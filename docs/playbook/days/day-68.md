Payback questions look easy, and they are. The marks are in what you say next.

Made-up example: a client can spend $500,000 on new machines that save $125,000 a year. How long until they pay for themselves?
$500,000 ÷ $125,000 = 4 years.

Then add judgement:
- If the savings only start after 6 months, payback is 4.5 years.
- If the machines last 5 years, the client ends up only $125,000 ahead in total ($625,000 saved, $500,000 spent), before any running costs.
- So ask how long the machines last, and how sure the savings are, before saying yes.
