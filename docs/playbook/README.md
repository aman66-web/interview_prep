# Growth playbook (written 15 Oct 2026)

The founder's day-by-day plan to launch Mock Partner and grow it toward $10,000 a month. He follows it from the private page https://claude.ai/artifact/1kgsULhHkJX4bh7mdQmNzq (tick boxes, ready-to-paste messages, a daily numbers log). These files are the same plan, kept here so any Claude session can look up a day, a build or a rule the founder mentions.

| File | What is in it |
|---|---|
| `strategy.json` | The goal in customers, the funnel maths, the honest timeline, the 90-day goal, phases, the 13 weeks with milestones and aims, channels with stop rules, gates (Days 10, 30, 45, 60, 90), budget caps, offers, the builds (B1-B22, each with its day and message), the recruiting calendar, the daily routine, after Day 90, and the do-not list |
| `days.json` | Days 1-90 (Day 1 = Fri 16 Oct 2026): each day's title, why, tasks (`who`: `you`, `claude` = a Claude Code cloud session, `chrome` = Claude in Chrome on the founder's computer), steps, the exact text to paste, numbers to log and decision points |
| `days/day-01.md` ... `days/day-90.md` | The same days as readable pages, one per day, for Claude in Chrome to open each morning |
| `CHROME_DAILY_PROMPT.md` | The prompt the founder pastes into Claude in Chrome every morning to do that day's tasks |
| `research-market.md`, `research-calendar.md`, `research-channels.md` | The research the plan rests on, with a source URL and date for every fact (competitors and prices, recruiting dates, channel costs and rules, UK law) |

How it was made: three researchers, one strategist, three writers (one per 30 days) and three separate checkers who fixed rule breaks, unbacked facts, impossible steps and contradictions; then the lead aligned the months (one ads rule, batch names, a third video kit, the search plan saved in the repo).

Rules that still apply: every number is a labelled aim, not a forecast; nothing that costs money happens without the founder's yes; the CLAUDE.md rules (no fake proof, firm names only descriptively, no marketing email without opt-in, no ad tag before the consent banner) win over anything here.
